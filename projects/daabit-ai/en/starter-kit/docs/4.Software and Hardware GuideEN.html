The micro:bit is a pocket-sized computer, half the size of a credit card, designed by the BBC in collaboration with Microsoft, Samsung, ARM, and other partners for youth programming education. 4.5 WonderLLM Module ​

4.5.1 Module Introduction ​

1. Module Overview ​

WonderLLM is an AI Large Language Model module with an onboard ESP32-S3 high-performance chip. It integrates a 2-megapixel high-definition camera, microphone, high-definition display screen, speaker, and CI1302 voice recognition chip, deeply integrating multimodal models including text, voice, and vision.

Featuring easy operation, this module is frequently paired with robots to function as a super brain. It deeply understands instructions, granting robots outstanding perception, reasoning, and action capabilities to build a flexible and natural human-robot interaction experience.

2. Operating Principle ​

  • The module is woken up using a command word. Speak the wake-up word to activate WonderLLM. Human-robot interaction can proceed only after activation. To switch to English recognition, the English recognition firmware must be flashed. After switching to the English firmware, the English wake-up keyword is Hello Hiwonder.

  • When recognizing the wake-up word, the buzzer beeps once, after which interaction begins. The module supports communication in English. If no voice is recognized within one minute, the module enters sleep mode, requiring reactivation for subsequent use.

3. Hardware Port Overview ​

No.Description
1Upper Type-C port, used for flashing program firmware to the ESP32-S3 chip
2Lower Type-C port, used for flashing voice recognition firmware to the CI1302 chip
34-PIN I2C communication port, available for secondary development
4Capacitive touch screen, used for displaying interfaces and adjusting volume
5Left button, used for switching expression or chat modes
6High-definition camera, capable of capturing real-time images
7Right button, used for module network configuration and interaction control

4. Precautions ​

  1. Use a 5 V power supply, otherwise the module will be damaged.

  2. The operating environment should be quiet, as noisy surroundings affect recognition accuracy.

  3. Speak clearly at a moderate speed, maintaining a distance within 5 meters from the module.

4.5.2 Module Configuration ​

1. Device Startup ​

  1. Powering the module is supported via the following ports: 1. Upper Type-C port, 2. Lower Type-C port, 3. 4-PIN I2C communication port. Connect an external power supply to any port, and the module powers on automatically.
  1. After powering on, the screen displays the device hotspot name and browser network configuration URL accompanied by voice broadcast. Complete device network connection first by following Module Network Connection.
  1. After network configuration, binding with the platform agent is required. The screen displays the device ID and device binding platform URL accompanied by a voice broadcast of the verification code. Complete device binding by following Device Binding.
  1. If device binding is complete upon powering on, a white circular scroll bar appears on the screen while the module connects automatically based on stored Wi-Fi information. If network connection fails, the screen displays the device hotspot name and browser network configuration URL accompanied by voice broadcast. Reconfigure valid Wi-Fi connection information for the current environment by following Module Network Connection.
  1. If device binding is complete upon powering on and configured Wi-Fi information is available in the current environment, the white circular scroll bar loads before network connection succeeds, jumping to the expression display interface. With all configurations normal, human-robot interaction begins after waking up the module.

2. Module Network Connection ​

  • Operation Description

  The module enters network configuration mode under three conditions: 1. Initial use or firmware re-flashing where no valid Wi-Fi information is saved in memory, 2. No matching hotspot exists in the current environment, 3. Manual operation long pressing button B to enter network configuration mode.

  • Operating Steps
  1. Network connection starts upon powering on the module. The screen displays the device hotspot name and browser network configuration URL accompanied by voice broadcast. The Large Language Model module opens its built-in hotspot for connection and configuration. Hotspot names vary across devices with a standard format “Robot-xxxx”, taken Robot-B7B9 as an example below.
  1. Search for the corresponding hotspot using a computer or phone and connect, note that this hotspot has no password.
  1. Click the hyperlink Network Configuration to directly access the device configuration URL, or copy the URL below to open in any browser.
py
http://192.168.4.1
  1. Enter the desired hotspot name for automatic connection in field 1 shown below, and enter the password in field 2. Click Connect in field 3 to search for and connect to a matching hotspot in the current environment.
  1. A list of available hotspots in the current environment scanned by the module appears on the interface. Click any item to automatically populate the hotspot name into field 1.
  1. If the prompt below appears on the interface, the hotspot cannot be found in the current environment or the password is incorrect. Re-enter the information.
  1. If the prompt below appears on the interface, the module found and connected to the hotspot successfully. The module restarts automatically and connects to the hotspot.

NOTE

  • Do not enter hotspots that cannot be scanned, have weak signals, or do not support network connection.

  • If connection information for other hotspots was saved previously, new saved information coexists. Upon next startup, stored information is read sequentially to attempt hotspot connection.

  • If the message "Error: Failed to check for new version, retrying in xx seconds" appears after configuration, the hotspot may lack internet access or network quality is poor. Try switching hotspots.

  • Manually Entering Network Configuration Mode

  1. The WonderLLM module supports manually entering network configuration mode to accommodate custom hotspot connection needs.

  2. After powering on the module, long press the right button to send a restart command, turning off the screen upon receipt. Continue long pressing. After restarting, the module attempts to connect to a hotspot while displaying a white circular scroll bar. Detecting that the right button is long pressed, the module stops matching external hotspots and enters network configuration mode directly. Release the button at this point.

  3. Stored hotspot configuration information is retained after entering network configuration mode. Access the network configuration page or short press the right button to exit network configuration mode.

  4. After exiting network configuration mode, the module continues attempting connection based on saved hotspot information. If connection to external hotspots fails, network configuration mode is re-entered.

  • Managing Saved Connection Configurations
  1. When the module is in network configuration mode, connect to the module hotspot to access the network configuration interface. The list of all saved hotspot connection configurations is displayed, as shown below:
  1. Click the icon corresponding to any saved hotspot connection information to delete it, or click the icon to raise its matching priority order during network configuration, where priority decreases from top to bottom.

4.5.5 Expression Mode ​

NOTE

  • If the wake-up word is not spoken within 20 seconds in the expression interface, the module enters weather clock mode. Tap anywhere on the screen to return to expression mode.

  • Switching between these two modes changes the screen display content when entering chat mode.

  • During mode switching by short pressing the left button, the module operates in expression mode continuously. Short pressing the left button to switch to chat mode does not and cannot wake up the module to enter actual chat mode.

  • Specifically, if the display interface in chat mode is switched to the chat box interface by short pressing the left button, the module displays the chat box interface and Large Language Model response after activation by speaking the wake-up word or short pressing the right button.

  • If the display interface in chat mode is switched to expression interface by short pressing the left button, the module remains in expression interface after activation by speaking the wake-up word or short pressing the right button, making appropriate expressions based on replies.

  1. In this mode, the module mimics human facial expressions.

The module makes facial expressions based on spoken statements, mainly through two methods: 1. 4.5.6 Weather Clock Mode ​

NOTE

In weather clock mode, tap anywhere on the screen to return to expression mode. Alternatively, speak the wake-up word or short press the right button to enter chat mode.

1. Mode Overview ​

  1. In this mode, the module obtains and displays real-time weather and time information based on the set city.

  2. The relationship for switching between various module modes is shown in the figure below. Operations to enter weather clock mode are summarized as follows: Tap the screen or perform no operation for 20 seconds in expression mode to enter weather clock mode. Camera mode and chat mode do not support direct switching to weather clock mode.

2. Operating Instructions ​

  1. In expression mode, perform no operation for 20 seconds or tap anywhere on the screen to switch to weather clock mode.

  1. After entering weather clock mode, the module remains in this mode if no other operations are performed.

  2. In this mode, the screen displays the following content: 1. Real-time weather information for the current location and weather forecast for the next 2 days, 2. Current time and date, 3. Local city.

  3. Modifying the local city is supported. Speak the wake-up word or short press the right button to enter the chat interface and activate the module. Give commands to the WonderLLM module using statements such as: 1. Modify city, which requires specifying the target city in subsequent conversation, 2. Switch local city to a specified city. After the module replies, the location for weather clock mode switches synchronously.

4.5.7 Camera Mode ​

1. Mode Overview ​

  1. In this mode, the module calls the camera to continuously capture and display real-time images.

  2. The relationship for switching between various module modes is shown in the figure below. Operations to enter camera mode are summarized as follows: Double tap the screen in expression mode to enter camera mode. Weather clock mode and chat mode do not support direct switching to camera mode.

2. Operating Instructions ​

  1. Double tap anywhere on the screen in expression mode to switch to camera mode.

  1. In camera mode, the module calls the camera to continuously capture and display real-time images. The module remains in this mode if no other operations are performed.

  2. In camera mode, tap anywhere on the screen to trigger the scene understanding function, as detailed in Scene Understanding.

4.5.8 Free Chat ​

1. General Operations ​

  1. After powering on and completing network configuration, wake up the module by speaking the wake-up word or short pressing the right button to enter chat mode.

  2. Speeches can be made freely. The module understands statements and makes text and voice replies through connection with the cloud Large Language Model. Featuring memory function, multi-round continuous conversations are supported.

  3. After each round of conversation, including after waking up WonderLLM, the module continues listening. If no statement is recognized within one minute, the module stops listening automatically. The Large Language Model replies with an appropriate farewell phrase, displays it in the chat box interface, and broadcasts it. To continue interaction, wake up the module again by speaking the designated wake-up word or short pressing the right button.

  4. The conversation can be ended actively during interaction. Give commands to the WonderLLM module using statements such as: 1. Goodbye, 2. Okay, let's stop here. Upon receipt, the module replies with a farewell phrase and stops listening.

  5. The WonderLLM module supports a voice interruption function. While the module is speaking, which includes replying to statements, greeting, or saying goodbye, short press the right button. The module stops speaking immediately and starts listening to the next statement.

  6. The WonderLLM module supports bilingual recognition and speech in Chinese and English. Switch the working language directly using statements such as: 1. Can Chinese be spoken?, 2. Can English be spoken?.

  • Function Overview

  Some special functions are built into the module, which can be invoked by spoken statements during interaction. Give commands to the WonderLLM module using statements such as: 1. What features are available?, 2. Introduce available functions. The table below lists the special functions currently supported by the module:

4.5.9 Scene Understanding ​

NOTE

  • In the scene understanding function, the module does not support long-term observation. It only captures a real-time image and analyzes it after a command is given to enable this function.

  • In camera mode, double-tap the screen again to return to the expression interface.

  • Before clicking to trigger the function in camera mode, the module only captures real-time images through the camera and displays them on the screen, without calling the Large Language Model for analysis.

1. Voice Interaction Control ​

  1. After powering on, the module enters the expression interface. Speak the wake-up word or short press the right button to enter the chat interface and activate the module.

  2. Give commands to the WonderLLM module using statements such as: 1. Describe what is seen in front, 2. Please take a photo.

  3. Upon understanding the command, the camera captures a real-time image and displays it on the screen briefly for confirmation. The conversation box returns the image capture function, which requires no attention. The conversation box then displays and broadcasts the Large Language Model analysis of the image, which is randomly generated with appropriate meaning.

2. Touch Screen Trigger ​

  1. In expression mode, double tap anywhere on the screen to enter camera mode, where the screen displays the real-time view captured by the camera in front.
  1. In camera mode, tap anywhere on the screen to capture a real-time image. The image displays on the screen briefly for confirmation before returning to camera mode. The module broadcasts the image analysis automatically, which is randomly generated with appropriate meaning.

4.5.10 Firmware Update ​

1. ESP32-S3 Firmware Flashing ​

  1. Connect the upper Type-C port of the WonderLLM module to the computer using a USB cable.
  1. Open the file flash_download_tool_3.9.7.exe in the folder Appendix\WonderLLM Flashing Tool\ESP32-S3 Firmware Flashing Tool\flash_download_tool_3.9.7.
  1. Select ChipType as ESP32-S3. Keep other settings as default, then click OK.
  1. After opening the tool, click ... to select the program bin file to be flashed. Open the file WonderLLM_S3_V1.9.0-EN.bin in the folder Appendix\WonderLLM Firmware File\Online.

  1. Check the box on the left. Configure the remaining settings as shown in the figure below. Select the COM port corresponding to the module.

    NOTE

    If SPI MODE is set to DIO according to the configuration below and the module fails to work after flashing, try setting SPI MODE to DOUT and flash again.

  1. Click ERASE to clear the previously downloaded firmware, which is a required step, and wait until the status bar displays FINISH.
  1. Click START to download the selected firmware, and wait for the progress bar to complete to finish firmware download.

2. CI1302 Firmware Flashing ​

  1. Connect the lower Type-C port of the WonderLLM module to the computer using a USB cable.
  1. Open the file PACK_UPDATE_TOOL.exe in the folder Appendix\WonderLLM Flashing Tool\CI1302 Firmware Flashing Tool.
  1. Select the CI1302 chip, then click Update.
  1. Click Select Firmware to select the program bin file to be flashed. Open the file CI1302_K12_EN.bin in the folder Appendix\WonderLLM Firmware File\Online.
  1. Find the corresponding serial port and click to select it.
  1. Long press the left and right buttons A and B on the WonderLLM module simultaneously to start flashing, then wait for flashing to complete successfully.
